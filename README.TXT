This is a README

3 New Premade Themes were included in the RecipeBook project (Dark, Legacy-Dark, and Kegacy-Light). By opening the main.java file in any other IDE than BlueJ, the ThemeAdder will run, allowing the user to add a new Theme to Theme Wheel. (Something to pay attention to is that you need to open the entire file, and not only select the main, since doing so will result in the program not running properly from the lack of the rest of the java/HTML files)
